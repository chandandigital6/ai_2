# Growya Flutter Developer Pack — Release 3

Start with AI_STUDIO_API.md for new AI packages, model entitlements and generation results.
API_FUNCTIONS_GUIDE_HINDI.md maps endpoints to controller functions.
SETUP_HINDI.md explains deployment and approval.
Growya_Flutter.postman_collection.json contains all 411 API route templates, including 20 AI endpoints.

Other module contracts remain in Full_API_Reference.md and Growya_Full_API_Reference.html. Older AI sections in those files are superseded by AI_STUDIO_API.md / AI_STUDIO_API.html. Read entitlements.available_credits for usable package credits.

`growya_ai_client.dart` provides named API methods on top of `growya_api_client.dart`. This is a mobile/desktop integration example; Flutter web needs a different transport. Run your own Dart analyzer/build after integrating.
